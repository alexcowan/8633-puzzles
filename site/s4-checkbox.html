The checkbox that does nothing

The story: As Trent the Technician, I want to see only the parts that are in stock, so I don't quote a customer a part I can't get today.

A designer cleaned up the parts page last week and added an “In stock only” checkbox. It's supposed to work on its own: tick it and the backordered parts disappear right away, whether or not you've searched; untick it and they come back. Search still works. The box does nothing. Your job is to find out why using your browser's developer tools on this page.

Be ready to explain
  1. What the Console told you, and which file and line it pointed to.
  2. Where the agreement between the page's HTML and its code is, and which side broke it.
  3. The one-line change you'd commit, in which file, and why that side.
Opening the developer tools

Use Chrome or another Chromium browser (Edge, Brave, Arc). Press Cmd+Option+J on a Mac (Ctrl+Shift+J on Windows) to open the tools straight to the Console, or right-click the page, choose Inspect, and click the Console tab.

Errors in the Console are red. The link at the right of an error (a file name and a line number) opens that file at that line in the Sources panel. The Elements panel shows the page's HTML; right-click an element on the page and choose Inspect to jump to it.

You can change the HTML in Elements, and you can edit a file in Sources and press Cmd+S (Ctrl+S on Windows) to apply the edit. Both change this tab only. Nothing is saved to the site.

Safari works too, after you turn on Settings → Advanced → “Show features for web developers.” Ad blockers and password managers sometimes add their own errors to the Console. That's normal; look for the errors that name a file from this page.

Fix it in the tools, then check

  1. Tick “In stock only.” The two backordered parts (orange edge) should disappear. Nothing changes.
  2. Open the Console and read the red error. Click the file and line at its right.
  3. Find the two things that are supposed to match: one in the code, one in the HTML.
  4. Make them match, in the tools, on whichever side you'd fix: in Elements for the HTML, or in Sources for the code (edit the line, then press Cmd+S, or Ctrl+S on Windows, to apply it to this tab).
  5. Click Check the page. It re-runs the page's setup with your change, as if you'd saved it and reloaded, then ticks the box and looks at what shows.
