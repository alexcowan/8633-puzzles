Punch card: predict, then run

A café built its loyalty punch card into the register. Two stories, one from each side of the counter:

As Casey the regular, I want every tenth coffee free so that coming here every day pays off.

As “Bean There”’s owner, I want the register to run the punch card exactly the way the card on the counter says it works (one punch per coffee, the tenth is free, then a new card) so that regulars trust the program and I never give away coffee I didn't mean to.

Below are three scenarios that exercise the register. For each scenario, we write the Then together before anyone presses the button.

What we're practicing
  1. A Then says what Casey gets (what she pays, how many punches she has), not what the screen does.
  2. Write it first. Running the app is a check on your prediction, not a substitute for it.
  3. When the app and the stories disagree, the stories win. Which story catches which bug?

function ringUp(qty) {
  let charge = qty * PRICE;
  if (punches === 9 && qty === 1) {   // tenth coffee free, new card
    charge = 0;
    punches = 0;
    return charge;
  }
  if (punches > 0) punches += qty;      // add punches to the card
  return charge;
}
